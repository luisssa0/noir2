# NOIR CINEMA — учебный сайт бронирования

## Тема
Кинотеатр: выбор сеанса и мест на схеме зала, расчёт стоимости, оформление учебного билета, просмотр и отмена броней.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Для локального запуска без ограничений браузера можно использовать Live Server в VS Code.

Сборка, npm, сервер и платёжные сервисы не требуются. Интерфейс написан на HTML, CSS и ванильном JavaScript.

## Функции
- Девять реальных фильмов с постерами, названиями, жанрами и возрастными рейтингами.
- Два сеанса бронирования с разной начальной занятостью.
- Схема 4 × 6 (24 места), свободные/выбранные/занятые места.
- Выбор мест как на схеме, так и в списке.
- Фильтр по сеансу и максимальной цене; фильтр синхронно обновляет схему и список.
- Разная стоимость по рядам, автоматический пересчёт суммы.
- Подтверждение брони, электронный билет в «Мои билеты», отмена и освобождение мест.
- Сохранение броней в localStorage после обновления.
- Адаптивная вёрстка, управление с клавиатуры, видимый фокус, reduced-motion.

## Ограничения
Учебное демо: бронирования сохраняются только в этом браузере. Реальная оплата и покупка билетов не выполняются. Начальная занятость мест задана в JavaScript.

## Проверка
1. Выберите несколько свободных мест и убедитесь, что сумма меняется.
2. Подтвердите бронь — появится билет, выбранные места станут занятыми.
3. Обновите страницу — билет и занятость должны сохраниться.
4. Отмените билет — места снова станут доступны.
5. Переключите сеанс: у него отдельная занятость.
6. Проверьте фильтр цены, занятые места и мобильную ширину экрана.

## Промпты, использованные при разработке
1. «Создай адаптивный сайт кинотеатра на HTML/CSS/ванильном JS без сервера: два сеанса, зал 4 × 6, занятые места для каждого сеанса, выбор нескольких свободных мест и расчёт цены».
2. «Добавь подтверждение учебного билета, список моих билетов, отмену с освобождением мест и сохранение в localStorage. Не допускай двойного бронирования».
3. «Оформи сайт в тёмной кинематографичной эстетике: чёрный фон, градиенты от чёрного к красному, крупная гротескная типографика, плавные анимации, параллакс и адаптивная сетка».
